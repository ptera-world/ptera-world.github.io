# What is intelligence

LLMs aren't intelligent. That was my position too - it's the sensible one, the one you end up holding once you know [what's actually in there](/intelligence/what-is-a-llm#what-is-it-made-of). But "not intelligent" leans on a definition of intelligent, and I got curious what happens if you actually apply one. Not a rigged one. The standard one.

## The definition

Wikipedia, first line: intelligence is "the ability to perceive or infer information; and to retain it as knowledge to be applied to adaptive behaviors within an environment or context."

Three clauses. Perceive or infer. Retain. Adapt. A loop: take the world in, keep what you took, act differently because you kept it.

## The test

Perceive or infer: partial credit, and more than the dismissal usually grants. Within a conversation the inference is real - it [fills in what you must have meant](/intelligence/what-is-a-llm#why-does-english-finally-work), connects the thing on page one to the question on page ten. It only takes in what you push through the slot, but some of this clause is closed.

Retain: no. There's no path from experience to knowledge. What it knows [was pressed in at a factory, months ago](/intelligence/what-is-a-llm#does-it-know-things); what it learns from you [dies at the conversation's edge](/intelligence/what-is-a-llm#does-it-learn). Nothing that happens while it runs can change what it is.

Adapt: splits along the same cut. Inside the window, famously yes - two examples and it has the pattern. Across any boundary, zero. Tomorrow it makes the same mistake at the same confidence, because tomorrow it won't have had today.

So the loop is severed, at retain. The dismissal wins - on the memory clause, of all things. The boring one.

## Okay, so LLMs aren't intelligent.

Yes. But the first thing I tripped over: you've never used an LLM. Nobody has, not bare. Everything you've touched came wrapped - the chat product that keeps history and quietly writes notes about you, the coding agent that reads and edits files, even a plain instructions file in a folder. Prosthetic clauses, bolted on where retain should be.

And whether a bolted clause is real has a clean test: does the LLM's own running get to write it? A file it can only read is more frozen past. A file its own activity can edit means the next run behaves differently *because* the last run happened - and that isn't an imitation of retention. It's retention, implemented outside the thing.

So the definition works better as a diagnostic than a verdict: point it at any product, ask which clauses it actually closes and which it fakes. Both camps are aiming at the wrong object. The dismisser is dismissing a component nobody touches. The believer is crediting the component for the wrapper's loop.

## The person the clause disqualifies

The second thing I tripped over is heavier. A severed write path is a human condition. Anterograde amnesia: an injury closes the path from experience to memory, and a person lives entirely in the window. Everything from before is intact. Reasoning, wit, warmth - present, working. A conversation holds for minutes, then rolls. And the piano still plays - everything built before the door closed, they keep.

Run the definition. Perceive and infer: fully. Retain: dead - the same clause, dead the same way. And nobody would say "not intelligent." We say: they can't form new memories. A loss *inside* an intelligence - named that way because the word still applies. So the clause that carried the whole dismissal disqualifies a person it has no business disqualifying. Use memory to deny the machine, and you deny them too. I can't find a way through that keeps both.

## Obviously

"llms aren't intelligent. obviously." I still can't call them intelligent - the factory and the permanent first day are real. And I can't keep the "obviously" - it was standing on the one clause that just failed a person at a piano. I don't have a better definition to hand you, and I'm not going to pretend at one. The question in the title stays open. What's gone is the cheap way to close it, and the cheap way was the only way "obviously" ever worked.
